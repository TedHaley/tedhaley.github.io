Scoped to the job

An agent started in a repo sees that repo, its worktrees and its sessions. Name a scope to give it a few repos and a folder of specs.

Exact or by meaning

Agents use the same search you do: by meaning, by the exact identifier, or both, across code, docs and past sessions.

Works with your agent

Claude Code, Codex, Cursor or any MCP client, over stdio with pensieve mcp or over HTTP. pensieve integrate connects the agents on your Mac and adds a “search before you grep” block and skills, including optional ones that point you to teammates who know the code.

Measured, not promised

Fewer searches. Right file first.

We gave Claude Code the same code-finding tasks with and without Pensieve: held-out tasks across real repos from 500 to 33,000 files, asked five ways, from plain descriptions to exact names and error messages. It solves more of them with fewer tool calls, and the bigger the repo, the more it saves.

Questions.

What does Pensieve search?

Your files and folders (Documents, Desktop, Downloads and any folder you add), your git repositories including uncommitted changes and worktrees, and your Claude Code, Codex and Qwen Code sessions. Optionally Obsidian and Apple Notes too. Everything is indexed and searched on your Mac.

How does Pensieve save tokens?

Without it, a coding agent often greps the repo and reads many whole files to find what matters, and every file it reads costs tokens. With Pensieve connected over MCP, the agent asks one question and gets back the few most relevant passages with their file and line, so it reads less and starts on the right code. How much you save depends on the question and the repo; see the measured results above.

Does Pensieve make Claude Code cheaper?

In our benchmark, Claude Code with Pensieve solved 66 of 72 code-finding tasks against 62 with grep alone, with 40% fewer tool calls. Each lookup cost 9–10% less in 1,500–2,100-file repos and 21% less in a 33,000-file monorepo. Savings grow with repo size; the benchmark is open source so you can run it on your own code.

How do I get my agent to use Pensieve instead of grep?

Agents grep by habit. The install prompt runs pensieve integrate recommended, which adds a short “search before you grep” section to each agent's instructions file and a search skill for Claude Code. You can also switch these on in Settings → Search & Agents. With it, agents searched with Pensieve in 83% of lookups in our benchmark; without it, 26%.

Which agents work with Pensieve?

Any MCP client. pensieve integrate recommended connects Claude Code, Codex, Cursor, Gemini CLI, Windsurf, Claude Desktop and VS Code for you. Other agents can use pensieve mcp over stdio, or HTTP. Optional skills also suggest which teammates know an area and help plan new code around what already exists.

How does it find knowledge gaps?

Pensieve reads git blame and recent commit history for each area of a repo. Areas where most lines were written by people with no recent commits there are flagged, along with how many active people know the area and who among them knows it best.

Does anything leave my Mac?

No. Indexing and search run on your Mac. The only exception is if you choose Claude Code or Codex to write optional AI insights; those are labelled Cloud. The built-in model, a local server like LM Studio, or no AI at all keep everything local.

Do I need an AI model?

No. Search, agent context, ownership and knowledge gaps all work without one. AI insights are optional: choose the built-in Qwen 3.5 9B, LM Studio, Claude Code, Codex, or leave it off.

Is Pensieve free?

Yes. It's free and open source under the MIT license. The code is on GitHub.

Why does macOS ask before opening it?

The app isn't notarized yet. If macOS blocks it, open System Settings → Privacy & Security and click Open Anyway. You only do this once.

Does it work on Intel Macs or Linux?

The app needs Apple Silicon. On Linux and Intel Macs, the same prompt installs the backend and the browser visualizer, without the search panel.

How do I uninstall it?

Quit Pensieve, drag it to the Trash, and delete ~/.pensieve, ~/.local/share/uv/tools/pensieve and ~/.local/bin/pensieve.
