See your codebase as a map. Know who to ask about any part of it.

Pensieve is a free, open-source app that runs on your machine. It reads your git repos and your AI coding sessions, lays them out as an interactive 3D map, and tells you who knows each area, what they've shipped recently, and where teams are solving the same problem twice.

★ View on GitHubHow it works

Understand a whole codebase in your first ten minutes

Point Pensieve at your repos and it builds a map from the code and the git history you already have. Nothing to configure and no account.

A map of every repo

Every chunk of code is embedded and laid out in 3D, so related code sits together, even across repos. Browse it as a folder tree with owners, or open any area to see its files.

Who knows about X?

Ask about any concept, like "billing retries" or "auth tokens". Pensieve finds the relevant code and ranks the people who wrote it, using git blame and recent commits.

Teams solving the same problem

Overlaps finds folders, within or across repos, whose code does similar things but has different owners. These are likely duplicated work, or people who should talk.

What teammates are shipping

For each person: commits over the last 90 days, the areas they work in, and a plain-English summary of what they've been building.

Where to look next

Pensieve shows which parts of the code your work has touched, and ranks the nearby areas you haven't explored, with who to talk to about each one.

Your AI sessions, remembered

Every Claude Code, Codex and Qwen Code session becomes a searchable point on the map, with summaries, topics, the commits it produced, and chat that cites its sources.

How it works

One command installs it. The first run downloads a small embedding model and indexes in the background. The map fills in as it goes.

  1. Install

    Run the one-liner, or paste the prompt into your coding agent. Pensieve installs as a command-line tool with uv.

  2. Index

    It reads the repos your agent sessions ran in, plus any you add with pensieve --repos ~/code. Code, blame and history are indexed locally into ~/.pensieve.

  3. Explore

    Open localhost:8765. Browse the map, ask who knows what, and see who to reach out to. Press ⌘K to search everything.

Private by design

Your code never leaves your machine.

  • Embeddings run locally (Qwen3-Embedding-0.6B)
  • Chat and summaries use a local model via LM Studio, or any OpenAI-compatible server you choose
  • Session transcripts are read, never modified
  • Delete ~/.pensieve to remove everything

Requirements

Works on a typical laptop.

  • macOS or Linux, with git
  • About 2 GB of disk for the embedding model and index
  • Apple Silicon or CUDA if available; CPU works too
  • Optional: LM Studio with a chat model (qwen3.5-9b recommended) for summaries, insights and chat

FAQ

Does Pensieve send my code anywhere?

No. Everything runs on your machine. Code and transcripts are embedded with a local model and stored in ~/.pensieve. The optional chat model runs locally too.

Can I use it on a codebase without any AI coding sessions?

Yes. Run pensieve --repos ~/code to index every git repo under a folder. You get the codebase map, owners, who-knows-what, overlaps and team activity. Sessions add your own history on top.

How does it decide who knows an area?

It finds the code most relevant to your question with semantic search, then ranks people by how much of that code they wrote (git blame), alongside their recent commits in the area.

Which agents are supported?

Claude Code, Codex and Qwen Code transcripts are picked up automatically from their default folders. Other agents need a small parser; see the README.

Do I need a GPU?

No. Pensieve uses Apple Silicon or CUDA when it can and falls back to CPU, which is slower but works.

How do I update or uninstall it?

Update: uv tool upgrade pensieve. Uninstall: uv tool uninstall pensieve && rm -rf ~/.pensieve.
