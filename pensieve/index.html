Private by design

Your work stays on your Mac.

Indexing, search and the map run locally. You decide what gets indexed, and AI is entirely optional.

Runs locally

An on-device embedding model and a local index in ~/.pensieve. No account, no server.

Switch any source off

Agents, folders, repos and apps each have a switch. Turning one off removes what it indexed.

Secrets skipped

Password-manager exports, keys, .env files and credentials are never indexed.

AI if you want it

Summaries and insights are optional. Pick who writes them, or leave it off:

Drag Pensieve to Applications and open it. It sets itself up on first launch.

First launch. Pensieve isn't notarized yet, so macOS asks once: open System Settings → Privacy & Security and click Open Anyway. The first launch then downloads its search engine (about 1 GB).

Install with Terminal

Builds the app and adds the pensieve command for agents. Needs the Xcode command-line tools.

curl -fsSL https://tedhaley.ca/pensieve/install.sh | sh

Or ask your coding agent

Paste this into Claude Code or Codex:

Install Pensieve on my Mac by running PENSIEVE_NO_START=1 sh -c "$(curl -fsSL https://tedhaley.ca/pensieve/install.sh)". Then connect it to yourself with: claude mcp add pensieve -- pensieve mcp. Questions.

Is Pensieve free?

Yes. It's free and open source under the MIT license. The code is on GitHub.

Does anything leave my Mac?

No. Indexing, search and the map run on your Mac. The only exception is if you choose Claude Code or Codex to write AI insights; those are labelled Cloud. The built-in model, a local server like LM Studio, or no AI at all keep everything local.

What does it index?

Documents and folders in Documents, Desktop and Downloads (and any folder you add), git repos including uncommitted changes and linked worktrees, your Claude Code, Codex and Qwen Code sessions, and optionally Obsidian and Apple Notes. Every source has an off switch, and files that look like secrets are never indexed.

Do I need an AI model?

No. Search, the map, blame, activity and topics all work without one. AI insights are optional: choose the built-in Qwen 3.5 9B, LM Studio, Claude Code, Codex, or leave it off.

Why does macOS ask before opening it?

The app isn't notarized yet. The first time, open System Settings → Privacy & Security and click Open Anyway. You only do this once.

How do my coding agents use it?

Run claude mcp add pensieve -- pensieve mcp. Each agent works within a scope: by default the repo it was started in. Name a scope to give an agent several repos or folders.

Does it work on Intel Macs or Linux?

The app needs Apple Silicon. The backend and the browser visualizer also run on Linux and Intel Macs through the Terminal install, without the search panel.

How do I uninstall it?

Quit Pensieve, drag it to the Trash, and delete ~/.pensieve. If you used the Terminal install, also run uv tool uninstall pensieve.
